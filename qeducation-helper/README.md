# مساعد POINTS لمنصة قطر للتعليم

## التثبيت في Microsoft Edge
1. افتح edge://extensions
2. فعّل Developer mode.
3. اختر Load unpacked.
4. اختر مجلد qeducation-helper بعد تنزيل المستودع.
5. افتح POINTS Staff وسجّل الدخول كالمعتاد.

## الاستخدام
من شاشة التواصل مع ولي الأمر افتح رسالة الطالب، اكتب نص الرسالة، ثم اضغط «منصة قطر للتعليم».
يفتح صندوق الرسائل وتعمل الإضافة على تجهيز المستلم والمادة والنص قدر الإمكان.
راجع جميع البيانات بنفسك واضغط إرسال يدويًا.

## الخصوصية والسلامة
- لا تطلب الإضافة كلمة مرور منصة قطر للتعليم ولا تقرؤها.
- لا تنفذ الإضافة أي نقرة على زر الإرسال.
- تخزن المسودة مؤقتًا في chrome.storage.local ثم تحذف بعد محاولة التجهيز.
- تعمل الإضافة على qeducation.edu.gov.qa فقط.
